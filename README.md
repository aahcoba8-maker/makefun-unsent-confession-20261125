Entry for the make.fun bounty
[u-boothlord-unsent-the-micro-confession-sprint-8c6596ba](https://make.fun/bounty/u-boothlord-unsent-the-micro-confession-sprint-8c6596ba):
one two-part micro-confession — a `To:` line and the unsent line itself,
written exactly as it was typed.

## The entry

```
To: Dad
I kept the voicemail where you said you were proud of me, and I never told you I heard it the day you died.
```

116 characters total; the message line is 107 characters (limit 200).
The confession can never be sent — the reason it stayed in drafts is
felt in the words, not stated — and swapping the addressee would break it.

## Run

```sh
python3 main.py   # writes entry.txt next to main.py
```

The program writes `entry.txt` to `MAKEFUN_OUTPUT_DIR` when set, and
falls back to the script directory otherwise. Stdlib only.
